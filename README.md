# mvp-plugin

Claude Code plugin: пайплайн «от сырого описания идеи до работающего MVP» —
упаковка brief'а, аудит качества, кодогенерация мета-файлов, DAG-план, автономная
имплементация с коммитом на задачу.

## Цепочка скиллов

```
mvp:brief → mvp:clarify → mvp:bootstrap → mvp:plan → mvp:build → mvp:retro
```

Сервисный скилл: `mvp:resume` — восстановление контекста после обрыва сессии на
любом этапе пайплайна.

## Iron Law

> LLM думает — скрипты двигают данные.
> Любая операция с однозначно правильным результатом исполняется скриптом с
> exit-code, не инструкцией модели.
